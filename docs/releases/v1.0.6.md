# Túi Nhỏ v1.0.6

Phiên bản phát hành chính thức nâng cấp tính năng **gợi ý số tiền nhập nhanh 3 mốc thông minh** và bổ sung nút **Xóa trắng nhanh (X)** ngay trong ô nhập tiền.

Tải **tui-nho.apk** ở phần Assets bên dưới và cài đặt trên Android 7.0 trở lên. File `.sha256` dùng để kiểm tra tính toàn vẹn của tệp tải về.

## Có gì mới trong v1.0.6?

- **Gợi ý số tiền nhanh thông minh (Smart 3-Amount Suggestions)**:
  - Tự động gợi ý 3 mốc tiền chuẩn xác theo số đang gõ:
    - Ví dụ gõ `1` → Gợi ý ngay 3 nút: **`1.000 đ`**, **`10.000 đ`**, **`100.000 đ`**.
    - Ví dụ gõ `15` → Gợi ý: **`15.000 đ`**, **`150.000 đ`**, **`1.500.000 đ`**.
    - Ví dụ gõ `50` → Gợi ý: **`50.000 đ`**, **`500.000 đ`**, **`5.000.000 đ`**.
  - Thiết kế cố định 3 cột cân xứng, không bao giờ bị tràn màn hình hay gây rối mắt.
  - Lược bỏ hoàn toàn hàng số dài `+000.000` giúp giao diện thanh thoát, sang trọng.
- **Nút Xóa nhanh (X) tinh tế**:
  - Tích hợp nút tròn chữ X nhỏ gọn ngay trong ô nhập số tiền, xuất hiện khi có số và biến mất khi ô trống.
  - Xóa trắng tức thì toàn bộ ô nhập chỉ với 1 chạm.

## Hướng dẫn cập nhật

Bản phát hành này dùng chung Application ID `com.aithss.finance` và cùng khóa ký phát hành (Release Keystore) với các phiên bản trước. Bạn có thể:
1. Mở app hiện tại → App sẽ tự động quét và thông báo bản cập nhật v1.0.6 với thanh tải sóng Pixel.
2. Hoặc vào **Cài đặt → Cập nhật APK → Kiểm tra cập nhật APK**.
3. Hoặc tải trực tiếp file `tui-nho.apk` từ trang Release này để cài đè (giữ nguyên toàn bộ dữ liệu).
