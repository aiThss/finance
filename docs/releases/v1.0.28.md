# Túi Nhỏ v1.0.28

- Khắc phục triệt để lỗi Package Installer crash do icon ứng dụng trên Android 15 & Android 16 (`width and height must be > 0 at Bitmap.createBitmap`), đã xác minh hoàn tất cài mới và cập nhật giữ nguyên dữ liệu từ v1.0.19 / v1.0.21 trên emulator API 35 và API 36.
- Ổn định kịch bản native smoke test trên emulator CI: khởi tạo màn hình chính (Home Launcher) trước khi mở ứng dụng để root task chuyển đổi hợp lệ khi kiểm tra phím Back thu nhỏ ứng dụng.
- Đồng bộ toàn diện kiểm thử, build và phát hành APK chính thức.
