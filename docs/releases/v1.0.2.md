# Túi Nhỏ v1.0.2

- Sửa vùng thanh trạng thái Android, màu nền và độ tương phản ở giao diện sáng/tối; thu gọn Tổng quan, bỏ gạch chân sau khi chạm và blur thanh điều hướng.
- Thêm **Cài đặt → Cập nhật APK → Kiểm tra cập nhật APK**. Khi có bản mới, tải từ GitHub rồi mở APK để Android xác nhận nâng cấp.
- Thêm Gemini API key cá nhân: **Cài đặt → Trợ lý AI → Cách lấy API key**. Key Android được mã hóa bằng Android Keystore, không có trong bản sao lưu; yêu cầu đi thẳng đến Google. Không cần backend riêng hoặc VITE_API_BASE_URL cho APK. AI tùy chọn, ghi thu chi vẫn dùng ngoại tuyến.
- Tăng hiệu năng với lịch sử lớn, giới hạn truy vấn theo màn hình, sửa xử lý tài khoản lưu trữ và tách service worker PWA khỏi Android.

Ứng dụng giữ app ID `com.aithss.finance` và được ký bằng khóa release hiện có. Cài đè APK mới; không gỡ ứng dụng đang chứa dữ liệu. Nên xuất bản sao JSON trước khi cập nhật. Android có thể yêu cầu cho phép cài đặt từ nguồn bạn dùng để tải tệp.

AI: mở https://aistudio.google.com/api-keys, tạo key riêng, dán vào ứng dụng và bấm kiểm tra. Không chia sẻ key; theo dõi hạn mức/chi phí tại Google. Chưa kiểm chứng một yêu cầu Gemini thành công bằng key người dùng trong môi trường phát triển. Bản web giữ key cá nhân trong bộ nhớ tab và cần nhập lại sau khi tải lại trang.

Kiểm thử: lint, unit/server, browser E2E, build Android SDK 36 và native smoke trên emulator API 35. Chưa kiểm chứng mọi hãng điện thoại, bàn phím hoặc chế độ điều hướng; xem `docs/stabilization.md`.
