# Release v1.0.15

## Fixes & Enhancements

- **Khắc phục triệt để lỗi "Failed to fetch" khi tải APK cập nhật**:
  - Chuyển đổi phương thức tải file APK sang điều hướng tải trực tiếp qua trình duyệt/trình quản lý tải xuống hệ thống Android (`openApkDownload`), loại bỏ hoàn toàn việc bị chặn bởi chính sách CORS của GitHub Releases.
- **Tối ưu trải nghiệm: Thanh cập nhật gọn gàng dưới đáy màn hình (Non-blocking Compact Bottom Card)**:
  - Loại bỏ hoàn toàn modal dialog lớn ở giữa màn hình cùng lớp nền mờ che khuất ứng dụng.
  - Thông báo cập nhật được bố trí thành một thẻ bo góc thanh lịch (`.apk-update-bottom-card`) nằm gọn ngay phía trên thanh điều hướng dưới đáy.
  - Người dùng có thể thoải mái tiếp tục sử dụng ứng dụng (xem giao dịch, ghi chép, chuyển tab) bình thường trong khi kiểm tra và tải cập nhật mà không hề bị gián đoạn hay khóa màn hình.
  - Nút đóng (X) cho phép ẩn nhanh nếu muốn cập nhật sau.
