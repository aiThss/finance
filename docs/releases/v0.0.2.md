# Heo Nhỏ v0.0.2

- Đổi tên ứng dụng chính thức từ **Túi Nhỏ** thành **Heo Nhỏ** đồng bộ trên toàn bộ giao diện, tiêu đề trang, thanh điều hướng, Android system strings và manifest.
- Cập nhật biểu tượng logo bên cạnh tên ứng dụng trên Header di động và Sidebar máy tính sang hình ảnh Heo đất 3D chính thức.
- Nâng cấp phiên bản lên `v0.0.2` (Android `versionCode: 2`), hỗ trợ cập nhật đè trực tiếp mượt mà từ bản `v0.0.1`.
