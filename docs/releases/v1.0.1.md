# Túi Nhỏ v1.0.1

Tải **tui-nho.apk** ở Assets bên dưới và cài trên Android 7.0 trở lên. File `.sha256` dùng để kiểm tra tính toàn vẹn.

- Chữ và trường nhập lớn hơn, giao diện ghi chép gọn hơn.
- Điều hướng ưu tiên Tổng quan, Giao dịch, Ví tiền; công cụ phụ được thu gọn.
- Chuyển tab, mở và đóng form có hiệu ứng nhẹ, tôn trọng tùy chọn giảm chuyển động.
- Sửa cấu hình vùng thanh trạng thái/keyboard Android để tránh che phần đầu app.

## Chuyển từ v0.0.1
Bản v0.0.1 được ký bằng khóa debug. Từ v1.0.1 dùng khóa release cố định, nên Android không cho cài đè lên bản debug cũ.

1. Mở bản cũ → Cài đặt → Sao lưu JSON. Giữ file sao lưu ở nơi an toàn ngoài dữ liệu app.
2. Sau khi có bản sao lưu, gỡ bản debug cũ và cài `tui-nho.apk`.
3. Vào Cài đặt → khôi phục JSON, kiểm tra tài khoản và số dư.

Các bản release tiếp theo sẽ dùng cùng khóa để cập nhật tại chỗ. Không gỡ app chứa dữ liệu nếu chưa sao lưu.

Bản build này đã qua kiểm tra tự động; việc hiển thị thanh trạng thái, bàn phím và thao tác Back vẫn cần xác nhận trên điện thoại thật.
