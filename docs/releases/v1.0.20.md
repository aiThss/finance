# Túi Nhỏ v1.0.20

- **Cải tiến Updater Android**:
  - Triển khai state machine hoàn chỉnh (`idle` → `available` → `downloading` → `downloaded` → `installing` → `installed`), theo dõi tiến độ tải % thật thông qua Android `DownloadManager`.
  - Hỗ trợ lưu trữ trạng thái tải vào `SharedPreferences`, khôi phục tiến độ khi mở lại ứng dụng.
  - Sử dụng Android `PackageInstaller.Session` để cài đặt APK chuẩn native, xử lý chuyển hướng cấp quyền "Cài ứng dụng không rõ nguồn gốc" và khôi phục khi hoàn tất.
  - Đảm bảo an toàn: kiểm tra chữ ký ứng dụng (signing certificate) và package name trước khi cho phép cài đặt.

- **Banner Cập nhật Tinh gọn**:
  - Thiết kế thanh cập nhật tối giản với thanh tiến trình con giun mảnh (`WormProgress`), hiệu ứng chuyển động mượt mà, hỗ trợ `prefers-reduced-motion`.
  - Đồng bộ trạng thái giữa banner và trang Cài đặt thông qua hook chung `useApkUpdater`.

- **Cải tiến trang Cài đặt**:
  - Sắp xếp lại các mục theo thứ tự ưu tiên: Hiển thị → Trợ lý AI → Giao dịch định kỳ → Túi Nhỏ / Cập nhật → Dữ liệu của bạn.
  - Loại bỏ các trường thông tin không cần thiết (Tiền tệ VND, Ngôn ngữ Tiếng Việt).
  - Cập nhật nhãn rõ ràng: "Che số dư trên các màn hình".

- **Nhận diện Thương hiệu Mới "Túi Nhỏ"**:
  - Ra mắt biểu tượng vector Túi Nhỏ hình túi tiền mềm mại, hiện đại với ký hiệu `₫`.
  - Thay thế toàn bộ biểu tượng quyển sách cũ trên desktop sidebar, mobile header, Web/PWA, favicon và bộ launcher icon Android.

Kiểm chứng trước phát hành: 63 unit tests, lint sạch, build production hoàn tất, xác minh an toàn phiên bản và đồng bộ Capacitor Android.
