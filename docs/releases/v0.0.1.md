# Túi Nhỏ v0.0.1

- Khởi tạo phiên bản phát hành chính thức đầu tiên (v0.0.1) cho ứng dụng Túi Nhỏ (Finance).
- Cập nhật toàn bộ hệ thống nhận diện thương hiệu: Logo, Favicon, PWA icon, Splash screen và Adaptive Icon cho Android theo linh vật Heo đất 3D tiết kiệm tài chính mới.
- Tối ưu hóa toàn diện cấu trúc tài nguyên Adaptive Icon (108dp base, an toàn 100% trên các bộ launcher Android 15 & 16 / OxygenOS 16).
- Hỗ trợ đầy đủ quản lý tài chính cá nhân, tài khoản, danh mục, phân tích báo cáo và bảo mật cục bộ.
