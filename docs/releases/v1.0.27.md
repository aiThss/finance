# Túi Nhỏ v1.0.27

- Giữ bản sửa tài nguyên adaptive icon, đã qua cài mới và cập nhật giữ dữ liệu từ .19/.21 trên emulator API 35/36 ở bản thử nghiệm v1.0.25.
- Ổn định smoke test trên emulator: xử lý có giới hạn ANR của ứng dụng hệ thống trong mọi lần đọc giao diện, chờ nội dung trang chủ trước khi thử phím Back.
- Cấp 4 GB RAM và tắt spellchecker cho emulator smoke giống môi trường kiểm thử Package Installer.
- Không bỏ qua kiểm thử cài đặt, icon hoặc điều hướng để phát hành.

Chưa xác nhận trực tiếp trên OnePlus 15 / OxygenOS 16.
