# Túi Nhỏ v1.0.26

- Giữ bản sửa icon Túi Nhỏ theo mật độ màn hình, ngăn kích thước bitmap bằng 0 trong Package Installer.
- Hoàn thiện kiểm thử Android native: dùng đúng nút cập nhật hiện tại và xác minh phản hồi mạng, không dùng bộ chọn dành cho web.
- Giữ kiểm tra tài nguyên APK, kích thước drawable và cài mới/cập nhật giữ dữ liệu qua Package Installer trên API 35/36 trước khi phát hành.

Chưa kiểm chứng trực tiếp trên OnePlus 15 / OxygenOS 16.
