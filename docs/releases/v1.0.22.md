# Túi Nhỏ v1.0.22

- Sửa tài nguyên adaptive icon gây crash Package Installer khi bấm Cài đặt/Cập nhật.
- Giữ hình Túi Nhỏ, màu sắc và vùng đệm trong suốt; tạo foreground đúng mật độ 108dp và background vector có kích thước rõ ràng.
- Bổ sung kiểm tra icon ngay trong APK, đo kích thước runtime và kiểm thử cài/cập nhật qua giao diện hệ thống trên API 35/36, gồm giữ dữ liệu ví từ .19 và .21.

Đã tái hiện lỗi icon 0×0 của APK .20/.21 trên emulator. Chưa xác nhận trực tiếp trên OnePlus/OxygenOS; xem `docs/android-installer-icons.md` để biết phạm vi và bằng chứng kiểm thử.
