# Túi Nhỏ v1.0.23

- Giữ bản sửa icon của .22: foreground đúng mật độ, background 108dp, tránh icon 0×0 khi Package Installer tạo bitmap.
- Sửa bài kiểm thử CI bị chặn bởi hộp thoại ANR của Pixel Launcher trên emulator mới khởi động. Chỉ xử lý tối đa ba hộp thoại hệ thống đã biết, lưu ảnh/XML; không bỏ qua lỗi của Túi Nhỏ hay Package Installer.
- Thêm timeout cho lệnh ADB, bước chờ UI và job release; kiểm thử cài mới và cập nhật giữ dữ liệu trên API 35/36 vẫn bắt buộc trước khi phát hành.

.22 chưa được phát hành vì CI dừng ở bước kiểm thử giao diện. Chưa xác nhận trực tiếp trên OnePlus/OxygenOS.
