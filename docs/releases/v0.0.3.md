# Heo Nhỏ v0.0.3

- **Redesign giao diện route `/more` ("Góc của bạn")**:
  - Áp dụng hệ thống thẩm mỹ **Liquid Glass Private Command Deck** cao cấp với các thẻ kính quang học (`--glass-l1`, viền phản xạ ánh sáng mép trên `--specular-top` và đổ bóng phân tầng).
  - Bố cục thích ứng (Responsive Layout):
    - **Desktop / Tablet (>= 680px)**: Chuyển nhóm công cụ chính thành **Bento Grid 3 cột** trực quan, rộng rãi; nhóm "Công cụ khác" dàn đều dạng lưới 2 cột hiện đại.
    - **Mobile (< 680px)**: Thiết kế các hàng Optic Command Rows với vách ngăn hairline tinh tế, padding chạm an toàn (chuẩn 44px+), tối ưu hoàn hảo xuống tới kích thước hẹp 320px.
  - Phân loại trực quan bằng **Jewel Palette**: Mỗi mục được trang bị biểu tượng riêng biệt (Ngân sách - Heo đất Ngọc Lục Bảo `#10B981`, Báo cáo - Tăng trưởng Xanh Lam `#06B6D4`, Cài đặt - Thạch Anh `#64748B`, Định kỳ - Vàng Hổ Phách `#F59E0B`, Danh mục - Hồng Magenta `#D946EF`, Thùng rác - Đỏ San Hô `#F43F5E`).
  - Điểm nhấn **Prismatic Aurora**: Icon "Trợ lý AI" bọc viền chuyển sắc dạ quang tinh tế.
  - Tích hợp biểu ngữ bảo mật cục bộ khẳng định cam kết dữ liệu ngoại tuyến và riêng tư 100% trên thiết bị.
  - Tối ưu trợ năng: Điều hướng bàn phím hoàn chỉnh với focus ring `--accent` chuẩn WCAG, hỗ trợ đầy đủ chế độ giảm chuyển động (`prefers-reduced-motion: reduce`).
- Nâng cấp phiên bản lên `v0.0.3` (Android `versionCode: 3`).
